# Politique de sécurité

CyberPass manipule des preuves potentiellement sensibles. Merci de ne jamais publier
de vulnérabilité exploitable dans une issue publique.

Utilisez la fonctionnalité **Private vulnerability reporting** de GitHub pour décrire
le problème, son impact, les conditions de reproduction et, si possible, une piste de
correction. N’incluez aucune donnée réelle d’une organisation.

Le MVP n’est pas certifié et ne constitue ni une attestation de conformité ni un avis
juridique. Les versions de développement ne doivent pas recevoir de données de
production.
